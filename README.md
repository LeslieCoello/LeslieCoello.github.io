# Leslie Coello · Mi rincón pixel

Portafolio personal y **Pixel Focus**, un temporizador Pomodoro creado con HTML, CSS y JavaScript. Arte vectorial pixel original incluido en assets/room.svg.

## Funciones
- Enfoque de 25 minutos, descanso de 5 y descanso largo de 15.
- Iniciar, pausar, continuar y reiniciar.
- Cálculo por hora de finalización para compensar pestañas en segundo plano al regresar.
- Diseño adaptable y navegación por teclado.

## Ejecutar
Abrir index.html en el navegador. No requiere instalación ni servicios externos.

## Publicar con GitHub Pages
Subir el contenido de esta carpeta a la raíz de LeslieCoello/LeslieCoello.github.io. En Settings → Pages elegir Deploy from a branch, main y /(root), y guardar.

Dirección prevista: https://LeslieCoello.github.io/ (el enlace solo estará activo después de publicar).

## Validación pendiente de publicación
- Confirmar el despliegue exitoso de Pages en GitHub Actions.
- Abrir la URL pública y comprobar la presentación y los botones del temporizador.
- Guardar captura de Settings → Pages mostrando la URL y del despliegue exitoso.

La preparación local no demuestra por sí sola una publicación en GitHub Pages.
